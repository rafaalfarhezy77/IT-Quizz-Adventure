  • sets memuat satu atau beberapa Set A–D. Set dipakai sesuai kelompok.
  • Set berisi stages dengan kunci "1", "2", "3" berisi 10, 10, dan 5 soal.
  • Nomor global: 1–10, 11–20, 21–25. Jika nomor, tipe, atau bobot dihilangkan, struktur tahap menetapkan nilainya. Nilai yang disertakan harus sesuai tahap.
  • Tahap 1: options A–E dan correct_answer A–E.
  • Tahap 2: kunci Benar/Salah; studi kasus mini wajib pada nomor 8/9 (nomor global 18/19).
  • Tahap 3: setiap soal mempunyai case_study, kunci utama correct_answer, dan varian accepted_answers. Normalisasi hanya huruf besar/kecil dan spasi.
  • Tidak memakai member atau satu studi kasus per set. Format array 25 soal lama tetap diterima bila memenuhi aturan Networking.
  • Skor ketepatan 100; bonus global terpisah; stamp minimal 4/5 benar Tahap 3. Verifikasi sekitar 5 menit.
  • LOCKED atau sesi RUNNING menolak perubahan. Satu kesalahan membatalkan seluruh transaksi.
