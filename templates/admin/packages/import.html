Ketentuan Impor

  • File JSON maksimal 5 MB, dengan station: "Hardware" dan array packages.
  • ADD: kode paket wajib baru. Paket dibuat sebagai DRAFT.
  • UPDATE: kode wajib sudah tersedia. Seluruh isi paket diganti, status existing dipertahankan.
  • Kode tidak membedakan kapitalisasi. Kode duplikat atau kecocokan ambigu ditolak.
  • Isi judul, deskripsi studi kasus, petunjuk, URL HTTP/HTTPS, durasi 1–180 menit, batasan build, dan tujuh bobot dengan total 100%.
  • Paket LOCKED atau terikat sesi WAITING/RUNNING tidak dapat diperbarui.
  • Satu kesalahan membatalkan seluruh file. Pratinjau berlaku 30 menit dan kondisi database diperiksa ulang saat konfirmasi.
  • Aktivasi dan pemetaan Kelompok A–D dilakukan melalui menu Hardware setelah impor. Hasil dan snapshot submission lama tetap tersedia.
