SPESIFIKASI FORMAT

Ketentuan File CSV

  • Header Wajib: File CSV harus memiliki baris header dengan kolom: team_code,team_name,school,group
  • Pilihan Kelompok: Nilai pada kolom group harus berupa salah satu dari A, B, C, atau D.
  • Keunikan Kode: team_code harus unik (tidak boleh duplikat di dalam file maupun dengan data yang sudah terdaftar di database).
  • Format & Encoding: Mendukung file CSV standar (UTF-8) maupun hasil ekspor Microsoft Excel (UTF-8 dengan BOM).
  • Kebijakan All-or-Nothing: Jika ditemukan kesalahan pada satu baris data saja, seluruh proses import akan ditangguhkan sampai data diperbaiki.
Contoh Format Isi File:
team_code,team_name,school,group
A01,Team Alpha,SMAN 1 Madiun,A
A02,Team Beta,SMKN 1 Madiun,A
B01,Team Gamma,SMAN 2 Ngawi,B
C01,Team Delta,SMAN 1 Caruban,C
