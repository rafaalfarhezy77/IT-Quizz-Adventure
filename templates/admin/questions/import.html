SPESIFIKASI FORMAT JSON

Ketentuan Validasi Bank Soal

  • Paket Soal Didukung: Satu file dapat memuat pemetaan Set A, B, C, dan D di bawah kunci "sets".
  • Studi Kasus Software Engineering: Set dapat berisi case_study dengan title dan description, serta questions berisi tepat 9 soal bernomor 1–9. Format lama berupa array soal tetap diterima. Jika studi kasus tidak disertakan, studi kasus tersimpan tetap dipertahankan.
  • Pembagian Anggota Tim:
    Soal 1–3: Anggota 1 Soal 4–6: Anggota 2 Soal 7–9: Anggota 3
    File akan ditolak jika giliran anggota tidak sesuai dengan urutan soal di atas.
  • Kelengkapan Pilihan: Setiap soal wajib memiliki 4 opsi jawaban: A, B, C, dan D.
  • Kunci Jawaban Valid: Kunci jawaban harus tepat salah satu dari huruf A, B, C, atau D.
  • Proteksi Set LOCKED: Paket soal yang berstatus LOCKED di database tidak dapat diubah melalui import.
  • Kebijakan All-or-Nothing: Transaksi bersifat atomik. Jika ditemukan 1 baris error, seluruh proses import dibatalkan (tidak ada data parsial).
